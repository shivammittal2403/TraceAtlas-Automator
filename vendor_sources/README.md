# Readable vendor source snapshots

These are **actual Git-tracked files**, not submodule pointers. They were copied from the three pinned upstream source repositories, with exclusions and the disabled vulnerable pdfkit dependency documented in MANIFEST.json. PDF export from the legacy Mr.Holmes code is unsupported. Git submodules under third_party/ remain the authoritative upstream references.

Each source tree retains its original LICENSE and authorship. Do not import or execute unreviewed third-party scripts inside TraceAtlas. OSINT-SPY and Mr.Holmes executable integrations remain blocked; theHarvester requires a separately maintained Python environment. See docs/integrations/THREE_OSINT_FRAMEWORKS.md.
