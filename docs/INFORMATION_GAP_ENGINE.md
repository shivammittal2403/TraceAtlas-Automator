# Visible knowledge gaps

The product reports missing independent support, absent source values,
hostile instructions, failed/skipped sources, no observations, identity review,
unconfigured search and human report release. A source outage is a coverage gap,
never evidence that an entity or event is absent.

Structured projections cap at 200 facts while retaining the captured document;
truncation adds a gap. Remaining unknowns are included in draft and result. A full
objective-based uncertainty model and measured expected information gain remain
future work.
