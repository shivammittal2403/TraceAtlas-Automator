# Acceptance gates

| Gate | Current proof | Open work |
|---|---|---|
| Registered exact authority | Local scope/expiry/kill tests | Hosted worker authority/ownership |
| Captured immutable evidence | Bytes/custody/metadata/replay tests | Object storage, external integrity anchoring |
| Material citations | Controlled reference coverage; zero released claims | Semantic citations and human release workflow |
| Contradictions/lineage | Controlled temporal/copy cases | Representative source evaluation |
| Provider resilience | Fixture failure/retry/attempt caps | Live entitlements, RDAP compatibility, real outages |
| Investigator flow | CLI product; existing browser regression | New hosted product view |
| Security/operations | Limited changed-path review, local regressions | Independent review, live tenant/Auth, recovery/load/pilot |

No production, parity or blueprint-completion gate becomes true because a fixture
passed. Full definition of done includes contracts/code/authority/schema/evidence,
provenance/uncertainty/failure/audit/telemetry/tests/security/docs/versioning and
representative golden investigation for each capability.
