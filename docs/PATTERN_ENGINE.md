# Deterministic patterns and limits

Implemented patterns in this slice are exact subject/predicate/value claim
grouping, transitive origin/content/owner lineage grouping and overlapping
single-value conflicts. Existing research similarity and CTI correlation remain
separate reusable services.

These rules are not a trained cluster/risk/causality engine. Source token Jaccard
near-duplicate threshold is a configurable heuristic, not calibrated confidence.
No personal sensitive traits, intent or guilt are inferred. Advanced pattern
models require held-out evidence and independent reviewer evaluation.
