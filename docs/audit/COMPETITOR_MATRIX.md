# Competitor landscape matrix

Reviewed: 2026-10-04. Capability statements below are vendor-published product descriptions and are not independently verified. This is a category comparison, not a feature-parity or performance claim.

| Product | Publicly described focus | Relevance to TraceAtlas | Evidence boundary |
|---|---|---|---|
| Social Links / SL Crimewall | Vendor describes OSINT collection, link analysis, visualization and automation over social/web/messaging and other data | Broad social investigation and analyst-facing link analysis are useful benchmark categories | No independent coverage, accuracy or scale measurement is asserted |
| Maltego | Vendor describes graph-based link analysis and integrations for OSINT and internal data | Graph investigation, transform/integration ecosystem and case workflow are comparison areas | Connector count, data coverage and product performance are not independently tested |
| SpiderFoot | Open-source automated OSINT tool with modular sources, scans and correlation | Useful open-source reference for configured automated collection/correlation | Module availability does not prove entitlement, runtime success or evidence quality |
| OpenCTI | Threat-intelligence platform centered on STIX-based knowledge graph and connectors/imports | Relevant CTI ingestion, entity/relationship and feed-management reference | CTI model does not equal broad SOCMINT or general-purpose case investigation |
| Recorded Future | Vendor describes intelligence graph, automated analysis and AI-assisted workflows | Enterprise intelligence graph and analyst assistance are benchmark categories | Vendor claims, telemetry reach and effectiveness are not independently verified |

## Product-state comparison

TraceAtlas currently has a bounded evidence/case pipeline, 26 approval-driven workforce adapters, an analyst-reviewed candidate-resolution service and graph/report/replay primitives. It has no demonstrated integrated SOCMINT workflow, no production-qualified sources, no hosted production acceptance and no measured parity results. Therefore **parity is not established**.
