# Dark intelligence boundary

Existing `sensitive/` workflows preserve redacted authorized/public/licensed
exposure metadata. The integrated workforce runner does not acquire onion
content, use credentials, purchase data or add a dark-web worker.

A future dedicated acquisition worker must record provider entitlement/purpose,
use isolated networking, sanitize content and preserve immutable evidence before
analysis. Ownership, privacy and retention policy remain deployment gates.
Current source catalogs are not proof of acquisition capability.
