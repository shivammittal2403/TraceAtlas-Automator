# Supply-chain state

Existing CI creates a CycloneDX SBOM for TraceAtlas's package artifact.
Package/source connectors and the new `dependency` predicate can retain asserted
relationships. G08 proves shared evidence/graph/replay behavior on synthetic
component records, not BOM parsing or dependency propagation.

SBOM/HBOM/OBOM/SaaSBOM/AIBOM, VEX/VDR and supplier/tier/facility/ownership models
need typed import parsers, license and identifier validation, propagation tests
and uncertainty-preserving graph adapters. Do not treat dependency as causation
or supplier association as wrongdoing.
