# Quality measures and limits

The runner uses no AI. Its controlled tests measure citation reference
coverage, released unsupported-material-claim count, expected verification state,
source grouping, contradiction visibility, no identity merge and offline replay.
These are contract/fixture measures, not factual-accuracy or investigator outcomes.

Held-out semantic extraction, model fallback quality, entity precision, lineage
quality, human correction rate and comparative investigation quality need
independent reviewers and representative authorized data. Existing AI advisory
benchmark remains separate. Do not collapse these into an AI accuracy percentage
or use G01–G12 as a claim of commercial-tool parity.
