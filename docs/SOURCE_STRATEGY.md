# Source strategy

Prefer implemented official/public read-only providers already governed by
source contracts. Domain dispatch uses DNS/RDAP/archive; IP dispatch uses
RDAP/InternetDB with target and version checks. Person/company records require
approved provenance, exact subject scope and review. No URL supplied in source
text becomes a fetch instruction.

Approved search is not bound in this slice; queries remain intent records and
its absence is a gap. Catalogs, country URLs, OpenCTI packages and model names do
not imply executable/live-qualified sources. RDAP redirects fail closed until a
vetted public-registry/bootstrap policy is added. Source license/ownership,
freshness and independence remain operator/reviewer responsibilities.
