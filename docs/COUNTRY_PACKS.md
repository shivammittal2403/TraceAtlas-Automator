# Country pack requirements

No country pack registry is implemented by this delivery. Existing sources
and research metadata remain reusable. Do not invent registry or court URLs.

Each future versioned pack needs country/language, verified official source URLs,
licenses/access restrictions, identifier schemas, safe search templates,
jurisdiction/privacy notes, health checks and timestamped verification artifacts.
A public URL alone does not authorize collection or prove coverage. See
SOURCE_STRATEGY.md for existing executable versus catalog boundaries.
