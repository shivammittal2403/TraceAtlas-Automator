# Dataset registry state

The existing research pack contains audited bibliographic records and
supports offline metadata search/gap planning. It is not a general Kaggle/Hugging
Face/Zenodo discovery or production training dataset registry.

The pipeline accepts approved source records, preserves bytes and source
provenance and reports assertions with uncertainty. A future Dataset model needs
license/version/collection time/schema, coverage, freshness, bias/privacy and
security review. Dataset inclusion never makes its contents ground truth.
