# Implemented features and limits

The integrated slice implements strict source records, scoped capture,
structured claim grouping, transitive source-lineage components, per-observation
temporal graph edges, timeline, deterministic verification, visible gaps,
rule-ranked review actions, immutable drafts and byte-checked offline replay.
Existing DNS/RDAP/archive/InternetDB contracts are reused rather than cloned.

No autonomous external action, identity merge, report release, paid model call or
private-account access is added. Search queries remain planning candidates.
See CURRENT_STATE.md and GAP_ANALYSIS.md for broader platform coverage.
